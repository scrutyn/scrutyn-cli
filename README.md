# Scrutyn CLI

Scrutyn protects npm and Python package installs with scanning and release-age quarantine. This repository distributes the CLI binaries; product source is private.

## Install on Linux or macOS

```sh
curl -fsSL https://scrutyn.com/install.sh | sh
```

Windows: download the amd64 or arm64 ZIP from Releases. Verify downloads against the release SHA256SUMS before running them.

Documentation: https://scrutyn.com/docs
